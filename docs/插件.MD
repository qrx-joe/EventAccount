
一、什么是 Plugin Marketplace？
Plugin Marketplace 是 Claude Code 的插件分发平台。团队将常用的 Skills（代码审查、文档撰写等）和 MCP Server 统一打包发布到自建 GitLab，成员通过 /plugin 命令一键安装，后续有更新时自动同步，无需手动管理文件。


二、安装方式
团队已搭建统一的 Plugin Marketplace，一键安装，自动更新。

Step 1：添加 Marketplace
如果你的项目是从团队仓库 git pull 的，Claude Code 会自动提示添加。也可以手动运行：
/plugin marketplace add https://gitlab.clouddreamai.com/clouddreamai-tools-public/plugin-marketplace.git

同时，请用同样的方法安装两个第三方的非常优秀的marketplace，必须安装。

1. UI-UX-PRO-MAX
非常优秀的前端设计工具，大幅提高前端质感
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill --scope user

2. Superpowers
下一代AI原生开发框架，真神无需多言
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace --scope user

Step 2：浏览并安装
/plugin
进入 Discover 标签，安装全部plugins
或者直接命令安装：
/plugin install nestjs-code-review@clouddreamai-tools


三、更新已安装的插件
方法一：手动更新（推荐）
更新单个插件到最新版本：
# 在claude code内输入
/plugin update nestjs-code-review@clouddreamai-tools
或通过命令行：
claude plugin update nestjs-code-review@clouddreamai-tools
注意：`/plugin marketplace update` 只刷新 marketplace 的插件目录（即"有哪些插件可以安装"），不会更新你已安装的插件。要更新已安装插件，必须用 `/plugin update`。

方法二：开启自动更新（Claude Code v2.0.70+）
Claude Code 支持在启动时自动更新 marketplace 及其已安装插件：
1. 运行 `/plugin`，切换到 Marketplaces 标签
2. 选择 clouddreamai-tools
3. 选择 Enable auto-update
开启后，每次启动 Claude Code 时会自动拉取最新插件，有更新时会提示重启。
第三方 marketplace 默认关闭自动更新，需手动开启。


四、卸载方式
/plugin uninstall nestjs-code-review@clouddreamai-tools
