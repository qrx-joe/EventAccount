一、项目需求
  仿照Luma.com，设计聚焦一线城市和新一线城市的、 面向线上活动的报名与管理平台，提供活动创建、报名、签到等一站式服务。

二、项目需求拆解
  注：下列所有功能除特殊标出，否则全部包含用户端、管理端双端
功能模块
1. 用户模块
      用户注册（手机号必填，邮箱可在报名时填写）
        用户登录（短信验证码）
        用户条款与隐私政策
        忘记密码 / 重置密码
2. 个人中心模块
      个人资料编辑（头像、昵称、个性签名）
        账号安全设置（手机号、密码、登录设备管理）
        偏好设置（系统外观）
        账号注销
3. 活动创建模块
      活动基本信息填写
      活动名称
      开始 / 结束日期时间
      活动地点（支持地图选点）
      活动描述（富文本编辑器）
      活动海报上传（本地上传 / 平台图床选择）
      活动设置
      公开 / 私密设置
      是否需要审核报名
      人数限制
        门票价格设置（免费 / 付费，支持多级别门票）
      活动草稿保存
4. 活动管理模块
      - 活动概览
        活动信息面板展示
        活动邀请快捷入口（生成含二维码的邀请海报）
        活动主办人管理（添加 / 移除协办人）
        活动可见性设置
      - 参与者管理
        邀请参与者入口
          扫码签到功能
        参加者名单查看与导出
        签到状态管理（总参与者 / 已签到）
      - 活动报名管理
        报名开放 / 关闭控制
        人数限制调整
          门票管理（添加 / 编辑 / 删除门票类型）
        报名问卷设置（对接飞书多维表格/问卷）
        报名审核（通过 / 拒绝）
      - 更多操作
        复制活动
        取消活动
5. 活动列表模块
      我创建的活动列表
      我报名的活动列表
      活动状态筛选（进行中 / 已结束 / 草稿）
      快捷操作入口（签到、管理）
6. 社区模块
      - 社区管理
        创建社区
        社区基本信息设置（名称、简介、头像）
        社区成员管理
        活动归类管理
        活动草稿管理
        社区管理员设置
        社区标签管理
7. 发现模块（用户端首页）
      - 首页展示
        热门活动板块
          按类别浏览板块
        精选社区板块
        探索本地活动
      - 活动详情页
        活动海报展示
        活动基本信息（名称、所属组织、日期、地点）
        报名状态（名额剩余、是否需要审核）
        申请加入 / 报名入口
        活动详情内容展示
        相关活动推荐
      - 社区详情页
        社区创建者信息
        订阅社区按钮
        社区创建日期
        社区简介
        加入社区按钮
        社区内活动列表
        活动日历视图（按日期展示活动）
        地图视图（展示活动地点分布及数量）
8. 搜索模块
      活动搜索（关键词、分类、地点、日期）
      社区搜索
      搜索历史记录
9. 平台管理模块（仅管理员端）
      说明：平台管理功能集成在统一 Web 端中，管理员登录后可见
        用户管理（用户列表、封禁 / 解封）
      活动管理（活动审核、违规处理）
      社区管理（精选社区设置）
      内容审核（活动内容、用户举报处理）
        标签管理（活动标签、社区标签，允许用户创建，也允许平台管理员管理，需标明标签来源具体用户id或者平台）
      系统配置（参数配置）
10. 落地页展示
      未登录时的首页展示
三、技术栈
  - UI / UX：无，仿照Luma.com设计
  - 前端技术栈：Web 端： Vue 3 + Tailwind CSS + shadcn-vue + TypeScript
  - 后端技术栈：
    核心框架： Nest.js + TypeScript
    数据访问： TypeORM
  - 基础设施：
          部署方式： 基于 Docker 的 GitLab CI/CD
      数据库： 瑶池 PostgreSQL（Serverless）
      对象存储： 阿里云 OSS（按量付费）
      地图服务： 高德地图 API
      验证码服务：阿里云短信服务平台
